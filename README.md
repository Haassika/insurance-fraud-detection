Insurance Fraud Detection System (FraudSentinels)

This project is a machine learning-based web application to detect fraudulent insurance claims.

Features
- Real-time fraud probability prediction  
- Random Forest classifier  
- Streamlit web interface  

Tech Stack
Python, Pandas, NumPy, Scikit-learn, XGBoost, Streamlit

How to Run
pip install -r requirements.txt  
streamlit run app.py  

Note
Trained model files are generated from the notebook and are not included in this repository.
